# EfficientGov AI for Schools

**"Smarter Government Starts Local"**

An AI-powered web application that analyzes school district budgets to promote transparency and efficiency in education spending.

## About

EfficientGov AI is a student-built project for the Presidential AI Challenge 2026. It uses machine learning and AI to help citizens understand how their tax dollars are spent in schools.

## Features

- **Budget Analysis**: Upload or paste school budget text for AI-powered analysis
- **Efficiency Scoring**: Random Forest model calculates efficiency scores based on spending patterns
- **Spending Visualization**: Interactive charts showing budget breakdown
- **AI Insights**: Google Gemini AI provides plain-English explanations
- **Q&A Chat**: Ask questions about the budget and get AI-powered answers
- **Anomaly Detection**: Automatic flagging of unusual spending patterns

## Technology Stack

- **Frontend**: HTML, CSS, JavaScript
- **Machine Learning**: Random Forest-style efficiency scoring model
- **AI API**: Google Gemini 2.0 Flash Lite
- **Visualization**: Chart.js

## How It Works

1. Paste your school district's budget text
2. Click "Analyze Budget"
3. View efficiency score and spending breakdown
4. Ask questions about the budget via AI chat

## Files

- `index.html` - Main web application
- `style.css` - Styling
- `app.js` - Application logic
- `gemini.js` - Gemini API integration
- `model.js` - Random Forest efficiency scoring model

This project addresses the challenge of government efficiency by bringing budget transparency to the local level. When citizens understand their school's spending, they can advocate for better allocation of taxpayer dollars.
